# Plan 3: Lifter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the analysed program into C: one C function per recompiled function, plus a dispatch table. Every ARMv4T instruction is translated, and the C is checked against Unicorn by differential tests. `gbaport recompile` writes the sources for a game.

**Architecture:**
- **C contract.** `src/gbaport/lift/gba_cpu.h` defines the CPU state (`GbaCtx`, including banked registers). It also holds inline helpers for the shifter, the ALU flags, conditions, ARM7TDMI misaligned loads and stores, and CPSR/SPSR with mode switching. The runtime supplies the memory, BIOS, scheduler and miss hooks.
- **Instruction semantics.** `semantics.py` turns one decoded instruction into C statements. A write to r15 goes to a local `t`.
- **Functions.** `function.py` turns a CFG function into a C function. Blocks become labels and intra-function branches become gotos. Anything that leaves returns the address to continue at; switches over known cases stay inside the function. Loop heads check for due events.
- **Calls.** A call sets LR and runs `gba_call(ctx, next, return_address)`, which keeps looking up and running returned addresses until the chain comes back to the call's return address. Returns therefore end C calls, while tail calls and jumps stay flat. This also covers start-up code that sets LR itself before jumping.
- **Programs.** `program.py` emits prototypes, the code in chunks, and a sorted dispatch table with a binary-search `gba_lookup`.
- **Tests.** A C test host (`tests/lifthost.c`) runs batches of lifted snippets over a small flat memory. `tests/liftkit.py` runs the same snippets in Unicorn's ARM926 model and compares registers, flags and memory.

**Tech Stack:** Python 3.13 (stdlib at runtime). For tests: pytest, Keystone 0.9.2, Unicorn 2.1.3 and clang (LLVM 23.1.3, installed). The generated code is portable C11.

**Spec:** `docs/superpowers/specs/2026-10-17-gba-native-port-design.md` (roadmap row P3, plus the "Runtime model" and "Verification strategy" sections). Task 4 updates the spec's Calls/Returns bullets to the `gba_call` protocol described above.

## Review Focus

1. **ARM7TDMI behaviour Unicorn cannot check.** Unicorn can't check these:
   - misaligned LDR, LDRH, LDRSH, STR, LDM and SWP;
   - STM with the base in the list;
   - STR pc and register-shift reads of pc (+12);
   - C after a multiply.

   A wrong rule here silently corrupts game state. These are pinned in Task 2 (`test_misaligned_*`, the STM base-in-list cases in `test_block_transfers`). The pc+12 rules have no oracle, so check them against GBATEK.
2. **Exception returns and banked registers** (CPSR = SPSR, r8–r14 per mode). Getting them wrong breaks IRQ handlers. Pinned in Task 1 (`test_exception_return_restores_mode_banks_and_flags`) and Task 2 (`test_psr_transfers_and_banked_registers`).
3. **Call chains that don't come straight back.** These are tail calls, veneers, Thumb↔ARM interworking and code that sets LR itself before jumping. A wrong protocol returns into the wrong place or grows the C stack. Pinned in Task 3 (`TAIL_CALL`, `VENEER`, `ARM_TO_THUMB`, `THUMB_TO_ARM`, `EXPLICIT_LR` in `test_programs_match_unicorn`).
4. **Long-running loops must reach the scheduler.** Otherwise a recompiled game freezes. Pinned in Task 3 (`test_an_endless_loop_hands_control_to_the_scheduler`).
5. **Instructions C cannot express, and addresses without code,** must be reported or reach the runtime, never crash the lifter or silently fall through. Pinned in Task 3 (`test_an_instruction_c_cannot_express_is_reported`, `test_unrecoverable_paths_reach_the_runtime`) and Task 4 (`lift issues` in the CLI output).

```c
/* gba_cpu.h - CPU state and instruction helpers shared by recompiled code and the runtime.
 *
 * Recompiled functions have the type GbaFn: they run guest code starting at their
 * entry and return the guest address execution continues at (a return address, a
 * tail-call target, or any other jump target). gba_call() runs such a chain until
 * it reaches the return address of the call that started it, so returns end C
 * calls while tail calls and jumps never grow the C stack.
 *
 * The runtime provides the memory accessors (aligned addresses only; the CPU-level
 * helpers below apply the ARM7TDMI rules for misaligned loads and stores), the BIOS
 * (gba_swi), the scheduler (gba_events) and the handlers for undefined instructions
 * and addresses that have no recompiled function. */
#ifndef GBA_CPU_H
#define GBA_CPU_H

#include <stdint.h>

enum {
    GBA_MODE_USR = 0x10, GBA_MODE_FIQ = 0x11, GBA_MODE_IRQ = 0x12, GBA_MODE_SVC = 0x13,
    GBA_MODE_ABT = 0x17, GBA_MODE_UND = 0x1B, GBA_MODE_SYS = 0x1F,
};

struct GbaCtx;
typedef uint32_t (*GbaFn)(struct GbaCtx *ctx);

typedef struct GbaCtx {
    uint32_t r[16];             /* registers of the current mode; r[15] is unused */
    uint32_t n, z, c, v;        /* condition flags, each 0 or 1 */
    uint32_t cpsr_ctrl;         /* CPSR bits 0-27: mode, T, F, I */
    uint32_t spsr;              /* SPSR of the current mode (meaningless in USR/SYS) */
    uint32_t bank_r8_12[2][5];  /* r8-r12: [0] every mode but FIQ, [1] FIQ */
    uint32_t bank_r13_14[6][2]; /* r13, r14 of USR/SYS, FIQ, IRQ, SVC, ABT, UND */
    uint32_t bank_spsr[6];
    uint64_t cycles;            /* estimated CPU cycles run so far */
    uint64_t next_event;        /* gba_events() runs once cycles reach this */
    GbaFn (*lookup)(struct GbaCtx *ctx, uint32_t addr); /* recompiled function at addr */
    void *runtime;              /* owned by the runtime */
} GbaCtx;

/* Provided by the runtime. */
uint32_t gba_read8(GbaCtx *ctx, uint32_t addr);
uint32_t gba_read16(GbaCtx *ctx, uint32_t addr);
uint32_t gba_read32(GbaCtx *ctx, uint32_t addr);
void gba_write8(GbaCtx *ctx, uint32_t addr, uint32_t value);
void gba_write16(GbaCtx *ctx, uint32_t addr, uint32_t value);
void gba_write32(GbaCtx *ctx, uint32_t addr, uint32_t value);
void gba_swi(GbaCtx *ctx, uint32_t number);
void gba_undefined(GbaCtx *ctx, uint32_t addr);
void gba_events(GbaCtx *ctx);
GbaFn gba_missing(GbaCtx *ctx, uint32_t addr); /* no function recompiled at addr */

/* ---- control flow ---------------------------------------------------------- */

static inline void gba_call(GbaCtx *ctx, uint32_t next, uint32_t ret)
{
    while ((next ^ ret) & ~1u)
        next = ctx->lookup(ctx, next)(ctx);
}

#define GBA_EXIT(target) do { \
        uint32_t gba_exit_ = (target); \
        if (ctx->cycles >= ctx->next_event) gba_events(ctx); \
        return gba_exit_; \
    } while (0)

#define GBA_CHECK_EVENTS() do { if (ctx->cycles >= ctx->next_event) gba_events(ctx); } while (0)

/* ---- shifter: value, and the carry-out written through *c ------------------- */

static inline uint32_t gba_ror32(uint32_t v, uint32_t n)
{
    n &= 31;
    return n ? (v >> n) | (v << (32 - n)) : v;
}

static inline uint32_t gba_lsl(uint32_t v, uint32_t n) { return n < 32 ? v << n : 0; }
static inline uint32_t gba_lsr(uint32_t v, uint32_t n) { return n < 32 ? v >> n : 0; }
static inline uint32_t gba_asr(uint32_t v, uint32_t n)
{
    return (uint32_t)((int32_t)v >> (n < 32 ? n : 31));
}
static inline uint32_t gba_ror(uint32_t v, uint32_t n) { return gba_ror32(v, n); }
static inline uint32_t gba_rrx(uint32_t v, uint32_t c) { return (c << 31) | (v >> 1); }

static inline uint32_t gba_lsl_c(uint32_t v, uint32_t n, uint32_t *c)
{
    if (n == 0) return v;
    if (n < 32) { *c = (v >> (32 - n)) & 1; return v << n; }
    *c = n == 32 ? v & 1 : 0;
    return 0;
}

static inline uint32_t gba_lsr_c(uint32_t v, uint32_t n, uint32_t *c)
{
    if (n == 0) return v;
    if (n < 32) { *c = (v >> (n - 1)) & 1; return v >> n; }
    *c = n == 32 ? v >> 31 : 0;
    return 0;
}

static inline uint32_t gba_asr_c(uint32_t v, uint32_t n, uint32_t *c)
{
    if (n == 0) return v;
    if (n < 32) { *c = (uint32_t)((int32_t)v >> (n - 1)) & 1; return (uint32_t)((int32_t)v >> n); }
    *c = v >> 31;
    return *c ? 0xFFFFFFFFu : 0;
}

static inline uint32_t gba_ror_c(uint32_t v, uint32_t n, uint32_t *c)
{
    if (n == 0) return v;
    n &= 31;
    if (n == 0) { *c = v >> 31; return v; }
    *c = (v >> (n - 1)) & 1;
    return gba_ror32(v, n);
}

static inline uint32_t gba_rrx_c(uint32_t v, uint32_t *c)
{
    uint32_t result = (*c << 31) | (v >> 1);
    *c = v & 1;
    return result;
}

/* A rotated immediate sets the shifter carry to its bit 31. */
static inline uint32_t gba_imm_c(uint32_t imm, uint32_t *c)
{
    *c = imm >> 31;
    return imm;
}

/* ---- ALU ------------------------------------------------------------------- */

/* a + b + carry_in, setting N, Z, C (carry out) and V (signed overflow).
 * Subtractions are a + ~b + 1 (SUB, CMP) and a + ~b + C (SBC). */
static inline uint32_t gba_addc(GbaCtx *ctx, uint32_t a, uint32_t b, uint32_t carry_in)
{
    uint64_t wide = (uint64_t)a + b + carry_in;
    uint32_t r = (uint32_t)wide;
    ctx->n = r >> 31;
    ctx->z = r == 0;
    ctx->c = (uint32_t)(wide >> 32);
    ctx->v = ((~(a ^ b) & (a ^ r)) >> 31) & 1;
    return r;
}

static inline uint32_t gba_nz(GbaCtx *ctx, uint32_t r)
{
    ctx->n = r >> 31;
    ctx->z = r == 0;
    return r;
}

static inline void gba_nz64(GbaCtx *ctx, uint64_t r)
{
    ctx->n = (uint32_t)(r >> 63);
    ctx->z = r == 0;
}

/* ---- conditions ------------------------------------------------------------ */

#define GBA_EQ (ctx->z)
#define GBA_NE (!ctx->z)
#define GBA_CS (ctx->c)
#define GBA_CC (!ctx->c)
#define GBA_MI (ctx->n)
#define GBA_PL (!ctx->n)
#define GBA_VS (ctx->v)
#define GBA_VC (!ctx->v)
#define GBA_HI (ctx->c && !ctx->z)
#define GBA_LS (!ctx->c || ctx->z)
#define GBA_GE (ctx->n == ctx->v)
#define GBA_LT (ctx->n != ctx->v)
#define GBA_GT (!ctx->z && ctx->n == ctx->v)
#define GBA_LE (ctx->z || ctx->n != ctx->v)

/* ---- loads and stores with the ARM7TDMI's misalignment rules ----------------- */

static inline uint32_t gba_ldr(GbaCtx *ctx, uint32_t addr)
{
    return gba_ror32(gba_read32(ctx, addr & ~3u), (addr & 3) * 8);
}

static inline uint32_t gba_ldrh(GbaCtx *ctx, uint32_t addr)
{
    return gba_ror32(gba_read16(ctx, addr & ~1u), (addr & 1) * 8);
}

static inline uint32_t gba_ldrsb(GbaCtx *ctx, uint32_t addr)
{
    return (uint32_t)(int32_t)(int8_t)gba_read8(ctx, addr);
}

static inline uint32_t gba_ldrsh(GbaCtx *ctx, uint32_t addr)
{
    if (addr & 1)  /* a misaligned LDRSH loads the sign-extended byte */
        return gba_ldrsb(ctx, addr);
    return (uint32_t)(int32_t)(int16_t)gba_read16(ctx, addr);
}

static inline void gba_str(GbaCtx *ctx, uint32_t addr, uint32_t v) { gba_write32(ctx, addr & ~3u, v); }
static inline void gba_strh(GbaCtx *ctx, uint32_t addr, uint32_t v) { gba_write16(ctx, addr & ~1u, v & 0xFFFF); }
static inline void gba_strb(GbaCtx *ctx, uint32_t addr, uint32_t v) { gba_write8(ctx, addr, v & 0xFF); }

/* ---- modes, banked registers, CPSR and SPSR ------------------------------------ */

static inline int gba_bank(uint32_t mode)
{
    switch (mode & 0x1F) {
    case GBA_MODE_FIQ: return 1;
    case GBA_MODE_IRQ: return 2;
    case GBA_MODE_SVC: return 3;
    case GBA_MODE_ABT: return 4;
    case GBA_MODE_UND: return 5;
    default: return 0;
    }
}

static inline void gba_switch_mode(GbaCtx *ctx, uint32_t mode)
{
    int old_bank = gba_bank(ctx->cpsr_ctrl), new_bank = gba_bank(mode);
    if (old_bank != new_bank) {
        ctx->bank_r13_14[old_bank][0] = ctx->r[13];
        ctx->bank_r13_14[old_bank][1] = ctx->r[14];
        ctx->bank_spsr[old_bank] = ctx->spsr;
        if ((old_bank == 1) != (new_bank == 1)) {
            int was_fiq = old_bank == 1, is_fiq = new_bank == 1;
            for (int i = 0; i < 5; i++) {
                ctx->bank_r8_12[was_fiq][i] = ctx->r[8 + i];
                ctx->r[8 + i] = ctx->bank_r8_12[is_fiq][i];
            }
        }
        ctx->r[13] = ctx->bank_r13_14[new_bank][0];
        ctx->r[14] = ctx->bank_r13_14[new_bank][1];
        ctx->spsr = ctx->bank_spsr[new_bank];
    }
    ctx->cpsr_ctrl = (ctx->cpsr_ctrl & ~0x1Fu) | (mode & 0x1F);
}

static inline uint32_t gba_cpsr(const GbaCtx *ctx)
{
    return ctx->n << 31 | ctx->z << 30 | ctx->c << 29 | ctx->v << 28 | (ctx->cpsr_ctrl & 0x0FFFFFFFu);
}

/* MSR CPSR: fields is the instruction's mask (8 = flags, 1 = control). Outside USR mode
 * the control field sets the mode, I and F; the T bit cannot be changed this way. */
static inline void gba_set_cpsr(GbaCtx *ctx, uint32_t value, uint32_t fields)
{
    if (fields & 8) {
        ctx->n = value >> 31;
        ctx->z = (value >> 30) & 1;
        ctx->c = (value >> 29) & 1;
        ctx->v = (value >> 28) & 1;
    }
    if ((fields & 1) && (ctx->cpsr_ctrl & 0x1F) != GBA_MODE_USR) {
        gba_switch_mode(ctx, value & 0x1F);
        ctx->cpsr_ctrl = (ctx->cpsr_ctrl & ~0xDFu) | (value & 0xDF);
    }
}

static inline void gba_set_spsr(GbaCtx *ctx, uint32_t value, uint32_t fields)
{
    uint32_t mask = (fields & 8 ? 0xFF000000u : 0) | (fields & 1 ? 0xFFu : 0);
    ctx->spsr = (ctx->spsr & ~mask) | (value & mask);
}

/* Exception return (MOVS pc, lr / LDM ..., pc}^): CPSR = SPSR, including T. */
static inline void gba_restore_cpsr(GbaCtx *ctx)
{
    uint32_t saved = ctx->spsr;
    gba_switch_mode(ctx, saved & 0x1F);
    ctx->cpsr_ctrl = saved & 0x0FFFFFFFu;
    ctx->n = saved >> 31;
    ctx->z = (saved >> 30) & 1;
    ctx->c = (saved >> 29) & 1;
    ctx->v = (saved >> 28) & 1;
}

/* LDM/STM with ^ and no pc: transfer the USR-mode registers from a privileged mode. */
static inline uint32_t *gba_user_reg(GbaCtx *ctx, int n)
{
    int bank = gba_bank(ctx->cpsr_ctrl);
    if (n >= 13 && n <= 14 && bank != 0)
        return &ctx->bank_r13_14[0][n - 13];
```

```c
/* lifthost.c - runs lifted test programs against a small flat memory, for tests/liftkit.py.
 *
 * usage: lifthost INPUT OUTPUT
 *
 * INPUT holds a u32 case count, then per case: u32 case index, u32 r0-r14, u32 CPSR,
 * and the ROM, EWRAM and IWRAM windows (WINDOW bytes each). OUTPUT holds per case:
 * u32 status, u32 r0-r14, u32 CPSR and the EWRAM and IWRAM windows. A program stops
 * at "svc #0xff"; every other way out is a status the tests report. */
#define _CRT_SECURE_NO_WARNINGS /* fopen is fine here (MSVC's C library) */
#include <setjmp.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include "lifthost.h"

#define WINDOW 0x1000u
#define CYCLE_LIMIT 1000000u

enum { STOPPED = 1, RETURNED, UNDEFINED, MISSING, FAULT, RUNAWAY }; /* setjmp returns 0 first */

static uint8_t rom[WINDOW], ewram[WINDOW], iwram[WINDOW];
static jmp_buf escape;

static uint8_t *window(uint32_t addr, uint32_t size, int writing)
{
    uint32_t offset = addr & 0x00FFFFFFu;
    uint8_t *base;
    switch (addr >> 24) {
    case 0x02: base = ewram; break;
    case 0x03: base = iwram; break;
    case 0x08: base = writing ? NULL : rom; break;
    default: base = NULL; break;
    }
    if (base == NULL || offset + size > WINDOW)
        longjmp(escape, FAULT);
    return base + offset;
}

uint32_t gba_read8(GbaCtx *ctx, uint32_t addr) { (void)ctx; return *window(addr, 1, 0); }

uint32_t gba_read16(GbaCtx *ctx, uint32_t addr)
{
    uint8_t *p = window(addr, 2, 0);
    (void)ctx;
    return (uint32_t)p[0] | (uint32_t)p[1] << 8;
}

uint32_t gba_read32(GbaCtx *ctx, uint32_t addr)
{
    uint8_t *p = window(addr, 4, 0);
    (void)ctx;
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

void gba_write8(GbaCtx *ctx, uint32_t addr, uint32_t value) { (void)ctx; *window(addr, 1, 1) = (uint8_t)value; }

void gba_write16(GbaCtx *ctx, uint32_t addr, uint32_t value)
{
    uint8_t *p = window(addr, 2, 1);
    (void)ctx;
    p[0] = (uint8_t)value;
    p[1] = (uint8_t)(value >> 8);
}

void gba_write32(GbaCtx *ctx, uint32_t addr, uint32_t value)
{
    uint8_t *p = window(addr, 4, 1);
    (void)ctx;
    for (int i = 0; i < 4; i++)
        p[i] = (uint8_t)(value >> (8 * i));
}

void gba_swi(GbaCtx *ctx, uint32_t number)
{
    (void)ctx;
    if (number == 0xFF)
        longjmp(escape, STOPPED);
}

void gba_undefined(GbaCtx *ctx, uint32_t addr) { (void)ctx; (void)addr; longjmp(escape, UNDEFINED); }

GbaFn gba_missing(GbaCtx *ctx, uint32_t addr) { (void)ctx; (void)addr; longjmp(escape, MISSING); }

void gba_events(GbaCtx *ctx)
{
    if (ctx->cycles >= CYCLE_LIMIT)
        longjmp(escape, RUNAWAY);
    ctx->next_event = CYCLE_LIMIT;
}

static uint32_t read_u32(FILE *f)
{
    uint8_t b[4];
    if (fread(b, 1, 4, f) != 4) {
        fprintf(stderr, "lifthost: input truncated\n");
        exit(2);
    }
    return (uint32_t)b[0] | (uint32_t)b[1] << 8 | (uint32_t)b[2] << 16 | (uint32_t)b[3] << 24;
}

static void write_u32(FILE *f, uint32_t v)
{
    uint8_t b[4] = {(uint8_t)v, (uint8_t)(v >> 8), (uint8_t)(v >> 16), (uint8_t)(v >> 24)};
    fwrite(b, 1, 4, f);
}

static void read_window(FILE *f, uint8_t *dest)
{
    if (fread(dest, 1, WINDOW, f) != WINDOW) {
        fprintf(stderr, "lifthost: input truncated\n");
        exit(2);
    }
}

int main(int argc, char **argv)
{
    if (argc != 3) {
        fprintf(stderr, "usage: lifthost INPUT OUTPUT\n");
        return 2;
    }
    FILE *in = fopen(argv[1], "rb"), *out = fopen(argv[2], "wb");
    if (in == NULL || out == NULL) {
        fprintf(stderr, "lifthost: cannot open files\n");
        return 2;
    }
    uint32_t count = read_u32(in);
    for (uint32_t n = 0; n < count; n++) {
        static GbaCtx ctx;
        uint32_t index = read_u32(in);
        if (index >= HARNESS_CASE_COUNT) {
            fprintf(stderr, "lifthost: no case %u\n", index);
            return 2;
        }
        memset(&ctx, 0, sizeof ctx);
        for (int r = 0; r < 15; r++)
            ctx.r[r] = read_u32(in);
        uint32_t cpsr = read_u32(in);
        ctx.n = cpsr >> 31;
        ctx.z = (cpsr >> 30) & 1;
        ctx.c = (cpsr >> 29) & 1;
        ctx.v = (cpsr >> 28) & 1;
        ctx.cpsr_ctrl = cpsr & 0x0FFFFFFFu;
        ctx.next_event = CYCLE_LIMIT;
        ctx.lookup = HARNESS_CASES[index].lookup;
        read_window(in, rom);
        read_window(in, ewram);
        read_window(in, iwram);
        uint32_t initial_lr = ctx.r[14];
        int status = setjmp(escape);
        if (status == 0) {
            gba_call(&ctx, HARNESS_CASES[index].entry(&ctx), initial_lr);
            status = RETURNED;
        }
        write_u32(out, (uint32_t)(status - STOPPED));
        for (int r = 0; r < 15; r++)
            write_u32(out, ctx.r[r]);
        write_u32(out, gba_cpsr(&ctx));
        fwrite(ewram, 1, WINDOW, out);
        fwrite(iwram, 1, WINDOW, out);
    }
    fclose(in);
    fclose(out);
    return 0;
}
```

Create `tests/liftkit.py`:
```python
"""Run small programs both lifted to C and in Unicorn, and compare the end states.

A case is a snippet of assembly plus an initial state. The kit appends
``stop: svc`` with BIOS number 0xFF (``b .`` after it keeps the analysis short);
both runs end there, and snippets may branch to ``stop`` themselves.
``run_compiled`` builds one test binary from a C translation unit that defines the
case table (cached by the hash of its sources) and runs the cases with it;
``run_oracle`` executes the same cases in Unicorn's ARM926 model. Both report an
``Outcome``.

Memory is three 4 KiB windows: the ROM at 0x08000000 (the assembled snippet), EWRAM
at 0x02000000 and IWRAM at 0x03000000. Unicorn is an ARMv5 core, so tests stay
inside the behaviour ARMv4T shares with it: aligned memory accesses, and no
dependence on C or V after a multiply.
"""

import functools
import hashlib
import random
import shutil
import struct
import subprocess
import tempfile
from dataclasses import dataclass, field
from pathlib import Path

from ksasm import assemble
from progkit import CODE_ADDR
from romkit import build_rom
from unicorn import UC_ARCH_ARM, UC_MODE_ARM, UC_MODE_THUMB, Uc, UcError
from unicorn import arm_const as uc_arm

import gbaport.lift

WINDOW = 0x1000
ROM, EWRAM, IWRAM = 0x08000000, 0x02000000, 0x03000000
SYS_MODE = 0x1F
STATUSES = ("stopped", "returned", "undefined", "missing", "fault", "runaway")
HOST = Path(__file__).with_name("lifthost.c")
INCLUDE = Path(gbaport.lift.__file__).parent
CACHE = Path(tempfile.gettempdir()) / "gbaport-liftcache"
_UC_REGS = [getattr(uc_arm, f"UC_ARM_REG_R{n}") for n in range(13)] + [
    uc_arm.UC_ARM_REG_SP,
    uc_arm.UC_ARM_REG_LR,
]


@dataclass
class Case:
    source: str
    thumb: bool = False
    regs: list[int] = field(default_factory=lambda: [0] * 15)  # r0-r14
    flags: int = 0  # NZCV in bits 31-28
    mode: int = SYS_MODE
    ewram: bytes = bytes(WINDOW)
    iwram: bytes = bytes(WINDOW)

    @property
    def cpsr(self) -> int:
        return self.flags | self.mode | (0x20 if self.thumb else 0)

    def rom(self) -> bytes:
        return _rom(self.source, self.thumb)


# The number is in bits 16-23 of an ARM svc and in the low byte of a Thumb one.
TERMINATOR = {  # back in the case's own state: snippets may switch with .thumb / .arm
    False: "\n.align 2\n.arm\nstop:\n    svc #0xff0000\n    b .\n",
    True: "\n.align 1\n.thumb\nstop:\n    svc #0xff\n    b .\n",
}
STOP_MARKER = {False: bytes.fromhex("0000ffef"), True: bytes.fromhex("ffdf")}


@functools.lru_cache(maxsize=4096)
def _rom(source: str, thumb: bool) -> bytes:
    code = assemble(source + TERMINATOR[thumb], thumb=thumb, addr=CODE_ADDR)
    return build_rom(code, size=WINDOW)


@dataclass(frozen=True)
class Outcome:
    status: str
    regs: tuple[int, ...]  # r0-r14
    cpsr: int
    ewram: bytes
    iwram: bytes


def random_case(rng: random.Random, source: str, *, thumb: bool = False, **fields) -> Case:
    """A case with random registers, flags and RAM; ``fields`` override any of them."""
    regs = [interesting(rng) for _ in range(15)]
    case = Case(
        source,
        thumb=thumb,
        regs=regs,
        flags=rng.randrange(16) << 28,
        ewram=rng.randbytes(WINDOW),
        iwram=rng.randbytes(WINDOW),
    )
    for name, value in fields.items():
        setattr(case, name, value)
    return case


def interesting(rng: random.Random) -> int:
    """Mostly random words, often the edge values flags and shifts care about."""
    if rng.random() < 0.3:
        return rng.choice([0, 1, 2, 31, 32, 33, 0x7FFFFFFF, 0x80000000, 0xFFFFFFFF, 0xFFFFFFFE])
    return rng.getrandbits(32)


def clang() -> str:
    found = shutil.which("clang") or r"C:\Program Files\LLVM\bin\clang.exe"
    if not Path(found).exists():
        raise RuntimeError("clang not found: install LLVM (winget install LLVM.LLVM)")
    return found


def build(source: str) -> Path:
    """Compile the harness with ``source``; reuses an earlier build of the same sources."""
    digest = hashlib.sha1()
    for text in (source, HOST.read_text(), (INCLUDE / "gba_cpu.h").read_text()):
        digest.update(text.encode())
    folder = CACHE / digest.hexdigest()[:16]
    exe = folder / "lifthost.exe"
    if exe.exists():
        return exe
    folder.mkdir(parents=True, exist_ok=True)
    (folder / "cases.c").write_text(source, encoding="utf-8")
    command = [
        clang(), "-std=c11", "-O1", "-Wall", "-Werror", "-Wno-unused-label",
        f"-I{INCLUDE}", f"-I{HOST.parent}", str(HOST), str(folder / "cases.c"), "-o", str(exe),
    ]
    result = subprocess.run(command, capture_output=True, text=True, check=False)
    if result.returncode != 0:
        raise RuntimeError(f"clang failed:\n{result.stderr[-4000:]}")
    return exe


def run_compiled(source: str, cases: list[Case]) -> list[Outcome]:
    """Run ``cases`` with the harness built around ``source`` (it defines HARNESS_CASES)."""
    exe = build(source)
    with tempfile.TemporaryDirectory() as tmp:
        inp, out = Path(tmp) / "in.bin", Path(tmp) / "out.bin"
        with open(inp, "wb") as f:
            f.write(struct.pack("<I", len(cases)))
            for i, case in enumerate(cases):
                f.write(struct.pack("<16I", i, *case.regs))
                f.write(struct.pack("<I", case.cpsr))
                f.write(case.rom().ljust(WINDOW, b"\0")[:WINDOW] + case.ewram + case.iwram)
        subprocess.run([str(exe), str(inp), str(out)], check=True, timeout=30)
        data = out.read_bytes()
    size = 17 * 4 + 2 * WINDOW
    outcomes = []
    for i in range(len(cases)):
        chunk = data[i * size : (i + 1) * size]
        words = struct.unpack_from("<17I", chunk)
        ram = chunk[68:]
        outcomes.append(
            Outcome(STATUSES[words[0]], words[1:16], words[16], ram[:WINDOW], ram[WINDOW:])
        )
    return outcomes


def run_oracle(cases: list[Case]) -> list[Outcome]:
    return [_oracle(case) for case in cases]


def _stop_address(case: Case, code: bytes) -> int:
    marker, step = STOP_MARKER[case.thumb], 2 if case.thumb else 4
    for offset in range(len(code) - step, 0xBF, -step):  # the terminator is the last code
        if code[offset : offset + len(marker)] == marker:
            return ROM + offset
    raise ValueError("no stop marker in the case")


def _oracle(case: Case) -> Outcome:
    code = case.rom()
    uc = Uc(UC_ARCH_ARM, UC_MODE_THUMB if case.thumb else UC_MODE_ARM)
    uc.ctl_set_cpu_model(uc_arm.UC_CPU_ARM_926)
    for base in (ROM, EWRAM, IWRAM):
        uc.mem_map(base, WINDOW)
    uc.mem_write(ROM, code[:WINDOW])
    uc.mem_write(EWRAM, case.ewram)
    uc.mem_write(IWRAM, case.iwram)
    uc.reg_write(uc_arm.UC_ARM_REG_CPSR, case.cpsr)
    for reg, value in zip(_UC_REGS, case.regs):
        uc.reg_write(reg, value)
    status = "stopped"
    try:
        uc.emu_start(CODE_ADDR | (1 if case.thumb else 0), _stop_address(case, code), count=100000)
        if uc.reg_read(uc_arm.UC_ARM_REG_PC) != _stop_address(case, code):
            status = "runaway"
    except UcError:
        status = "fault"
    regs = tuple(uc.reg_read(reg) for reg in _UC_REGS)
    return Outcome(
        status, regs, uc.reg_read(uc_arm.UC_ARM_REG_CPSR),
        bytes(uc.mem_read(EWRAM, WINDOW)), bytes(uc.mem_read(IWRAM, WINDOW)),
    )


def differences(lifted: Outcome, oracle: Outcome, *, ignore_cv: bool = False) -> list[str]:
    """What differs between two outcomes, ignoring the T bit (and C and V if asked)."""
    flags = 0xF00000DF & ~(0x30000000 if ignore_cv else 0)
    found = []
    if lifted.status != oracle.status:
        found.append(f"status {lifted.status} != {oracle.status}")
    for n, (a, b) in enumerate(zip(lifted.regs, oracle.regs)):
        if a != b:
            found.append(f"r{n} {a:#010x} != {b:#010x}")
    if lifted.cpsr & flags != oracle.cpsr & flags:
        found.append(f"cpsr {lifted.cpsr:#010x} != {oracle.cpsr:#010x}")
    for name in ("ewram", "iwram"):
        a, b = getattr(lifted, name), getattr(oracle, name)
        if a != b:
            first = next(i for i in range(WINDOW) if a[i] != b[i])
            found.append(f"{name} differs from +{first:#x}")
    return found
```

```python
Unicorn is an ARMv5 core, so misaligned accesses (where the ARM7TDMI rotates or
truncates) are checked against the ARM7TDMI rules directly instead.

import struct

from liftkit import EWRAM, IWRAM, Case, assert_same, random_case, run_lifted

CONDS = ["", "eq", "ne", "cs", "cc", "mi", "pl", "hi", "ls", "ge", "lt"]


def aligned_base(rng: random.Random, region: int = EWRAM) -> int:
    return region + rng.randrange(0x200, 0xE00, 4)


def test_multiplies():

        "mul{s}{c} r0, r1, r2", "mla{s}{c} r0, r1, r2, r3", "umull{s}{c} r0, r4, r1, r2",

def arm_transfer(rng: random.Random) -> tuple[str, int]:
    """An ARM load or store with an aligned address, and the value for r2 (the index)."""
    op, size = rng.choice([("ldr", 4), ("str", 4), ("ldrb", 1), ("strb", 1), ("ldrh", 2),
                           ("strh", 2), ("ldrsb", 1), ("ldrsh", 2)])
    cond = rng.choice(CONDS)
    imm = rng.randrange(-0x40, 0x40) * size
    index = rng.randrange(-16, 16) * size
    sign = "-" if imm < 0 else ""
    forms = [f"[r1, #{sign}{abs(imm)}]", f"[r1, #{sign}{abs(imm)}]!", f"[r1], #{sign}{abs(imm)}",
             "[r1, r2]", "[r1, -r2]", "[r1, r2]!", "[r1], r2"]
    if size == 4 or op in ("ldrb", "strb"):
        forms += ["[r1, r2, lsl #2]", "[r1, r2, asr #1]"]
        index = rng.randrange(-16, 16) * 8  # keeps r2 >> 1 word-aligned too
    return f"{op}{cond} r0, {rng.choice(forms)}", index & 0xFFFFFFFF
```

```python
"""C statements for what one ARMv4T instruction does to registers, flags and memory.

ARM and Thumb share one model (Thumb decodes into ARM-equivalent operations), so
one translation serves both. Control flow is left to ``function.py``: a write
to r15 goes to the C local ``t`` instead, and the caller turns it into a jump,
a call or a return. Reads of r15 are compile-time constants (ARM +8, Thumb +4,
+12 for an ARM register-specified shift, word-aligned for Thumb literal loads).
"""

from gbaport.analysis.effects import PC, pc_value
from gbaport.isa.model import (
    COMPARE_OPS,
    DATA_PROCESSING_OPS,
    MOVE_OPS,
    Cond,
    Instruction,
    Mode,
    Op,
    ShiftKind,
)

LOGICAL_OPS = frozenset({Op.AND, Op.EOR, Op.TST, Op.TEQ, Op.ORR, Op.MOV, Op.BIC, Op.MVN})
CONDITIONS = {cond: f"GBA_{cond.name}" for cond in Cond if cond is not Cond.AL}
_LOADS = {Op.LDR: "gba_ldr", Op.LDRB: "gba_read8", Op.LDRH: "gba_ldrh",
          Op.LDRSB: "gba_ldrsb", Op.LDRSH: "gba_ldrsh"}
_STORES = {Op.STR: "gba_str", Op.STRB: "gba_strb", Op.STRH: "gba_strh"}
_LONG_MULTIPLY = {Op.UMULL: (False, False), Op.UMLAL: (False, True),
                  Op.SMULL: (True, False), Op.SMLAL: (True, True)}  # (signed, accumulate)


class LiftError(ValueError):
    """An instruction the lifter cannot express in C."""


def hexu(value: int) -> str:
    return f"0x{value & 0xFFFFFFFF:08x}u"


def read(ins: Instruction, n: int, extra: int = 0) -> str:
    """C expression for the value of register ``n`` as ``ins`` sees it."""
    if n == PC:
        return hexu(pc_value(ins) + extra)
    return f"ctx->r[{n}]"


def dest(n: int) -> str:
    return "t" if n == PC else f"ctx->r[{n}]"


def lift_effects(ins: Instruction) -> list[str]:
    """Statements for ``ins`` apart from control flow (and apart from its condition)."""
    op = ins.op
    if op in DATA_PROCESSING_OPS:
        return _data_processing(ins)
    if op in (Op.MUL, Op.MLA):
        return _multiply(ins)
    if op in _LONG_MULTIPLY:
        return _long_multiply(ins)
    if op in _LOADS or op in _STORES:
        return _single_transfer(ins)
    if op in (Op.LDM, Op.STM):
        return _block_transfer(ins)
    if op in (Op.SWP, Op.SWPB):
        return _swap(ins)
    if op is Op.MRS:  # only ARM code has MRS, so the T bit reads as clear
        return [f"ctx->r[{ins.rd}] = {'ctx->spsr' if ins.spsr else 'gba_cpsr(ctx) & ~0x20u'};"]
    if op is Op.MSR:
        value = hexu(ins.imm) if ins.imm is not None else read(ins, ins.rm)
        setter = "gba_set_spsr" if ins.spsr else "gba_set_cpsr"
        return [f"{setter}(ctx, {value}, {ins.psr_mask}u);"]
    if op is Op.SWI:
        number = ins.imm >> 16 if ins.mode is Mode.ARM else ins.imm
        return [f"gba_swi(ctx, 0x{number:02x}u);"]
    raise LiftError(f"{ins.addr:#010x}: no effects for {op.value}")


def cycles(ins: Instruction) -> int:
    """A rough cycle estimate; the scheduler only needs the right order of magnitude."""
    op = ins.op
    if op in _LOADS or op in (Op.SWP, Op.SWPB):
        return 3
    if op in _STORES:
        return 2
    if op in (Op.LDM, Op.STM):
        return 2 + len(ins.reglist)
    if op in (Op.MUL, Op.MLA):
        return 4
    if op in _LONG_MULTIPLY:
        return 5
    if op in (Op.B, Op.BL, Op.BX, Op.BL_LO):
        return 3
    return 1


def _operand2(ins: Instruction, carry: bool, extra: int) -> str:
    """The shifter operand; with ``carry``, the expression also sets ctx->c like the shifter."""
    if ins.imm is not None:
        if carry and ins.imm_rot:
            return f"gba_imm_c({hexu(ins.imm)}, &ctx->c)"
        return hexu(ins.imm)
    value = read(ins, ins.rm, extra)
    shift = ins.shift
    if shift is None:
        return value
    if shift.kind is ShiftKind.RRX:
        return f"gba_rrx_c({value}, &ctx->c)" if carry else f"gba_rrx({value}, ctx->c)"
    amount = f"(ctx->r[{shift.reg}] & 0xFFu)" if shift.reg is not None else f"{shift.amount}u"
    name = f"gba_{shift.kind.value}"
    return f"{name}_c({value}, {amount}, &ctx->c)" if carry else f"{name}({value}, {amount})"


def _data_processing(ins: Instruction) -> list[str]:
    op = ins.op
    if op is Op.ADD and ins.rn == PC and ins.target is not None:  # Thumb ADR
        return [f"{dest(ins.rd)} = {hexu(ins.target)};"]
    by_register = ins.shift is not None and ins.shift.reg is not None
    extra = 4 if by_register and ins.mode is Mode.ARM else 0
    exception_return = ins.s and ins.rd == PC
    flags = ins.s and not exception_return
    operand = _operand2(ins, carry=flags and op in LOGICAL_OPS, extra=extra)
    a = None if op in MOVE_OPS else read(ins, ins.rn, extra)
    if op in LOGICAL_OPS:
        value = {
            Op.AND: f"{a} & op2", Op.TST: f"{a} & op2", Op.EOR: f"{a} ^ op2",
            Op.TEQ: f"{a} ^ op2", Op.ORR: f"{a} | op2", Op.BIC: f"{a} & ~op2",
            Op.MOV: "op2", Op.MVN: "~op2",
        }[op]
        if flags:
            value = f"gba_nz(ctx, {value})"
    else:
        x, y, carry_in = {
            Op.ADD: (a, "op2", "0"), Op.CMN: (a, "op2", "0"), Op.ADC: (a, "op2", "ctx->c"),
            Op.SUB: (a, "~op2", "1"), Op.CMP: (a, "~op2", "1"), Op.SBC: (a, "~op2", "ctx->c"),
            Op.RSB: ("op2", f"~{a}", "1"), Op.RSC: ("op2", f"~{a}", "ctx->c"),
        }[op]
        value = f"gba_addc(ctx, {x}, {y}, {carry_in})" if flags else f"{x} + {y} + {carry_in}"
    body = [f"uint32_t op2 = {operand};"]
    if op in COMPARE_OPS:
        body.append(f"(void)({value});")
    else:
        body.append(f"{dest(ins.rd)} = {value};")
    if exception_return:
        body.append("gba_restore_cpsr(ctx);")
    return _scoped(body)


def _multiply(ins: Instruction) -> list[str]:
    value = f"{read(ins, ins.rm)} * {read(ins, ins.rs)}"
    if ins.op is Op.MLA:
        value += f" + {read(ins, ins.rn)}"
    if ins.s:  # C is left alone (the ARM7TDMI leaves it meaningless), V unchanged
        value = f"gba_nz(ctx, {value})"
    return [f"ctx->r[{ins.rd}] = {value};"]


def _long_multiply(ins: Instruction) -> list[str]:
    signed, accumulate = _LONG_MULTIPLY[ins.op]
    rm, rs = read(ins, ins.rm), read(ins, ins.rs)
    if signed:
        product = f"(uint64_t)((int64_t)(int32_t){rm} * (int32_t){rs})"
    else:
        product = f"(uint64_t){rm} * {rs}"
    body = [f"uint64_t p = {product};"]
    if accumulate:
        body.append(f"p += (uint64_t)ctx->r[{ins.rd_hi}] << 32 | ctx->r[{ins.rd}];")
    if ins.s:
        body.append("gba_nz64(ctx, p);")
    body += [f"ctx->r[{ins.rd}] = (uint32_t)p;", f"ctx->r[{ins.rd_hi}] = (uint32_t)(p >> 32);"]
    return _scoped(body)


def _offset(ins: Instruction) -> str:
    if ins.rm is None:
        return hexu(ins.imm)
    value = read(ins, ins.rm)
    shift = ins.shift
    if shift is None:
        return value
    if shift.kind is ShiftKind.RRX:
        return f"gba_rrx({value}, ctx->c)"
    return f"gba_{shift.kind.value}({value}, {shift.amount}u)"


def _single_transfer(ins: Instruction) -> list[str]:
    if ins.rn == PC and ins.target is not None:  # literal pool (Thumb: word-aligned pc)
        address, written_back = hexu(ins.target), None
    else:
        base = read(ins, ins.rn)
        moved = f"{base} {'+' if ins.up else '-'} {_offset(ins)}"
        address = moved if ins.pre else base
        written_back = moved if ins.writeback else None
    body = [f"uint32_t addr = {address};"]
    if ins.op in _STORES:
        extra = 4 if ins.rd == PC and ins.mode is Mode.ARM else 0  # STR pc stores pc + 12
        body.append(f"uint32_t v = {read(ins, ins.rd, extra)};")
        if written_back is not None:
            body.append(f"ctx->r[{ins.rn}] = {written_back};")
        body.append(f"{_STORES[ins.op]}(ctx, addr, v);")
    else:
        if written_back is not None:
            body.insert(0, f"uint32_t wb = {written_back};")
        body.append(f"uint32_t v = {_LOADS[ins.op]}(ctx, addr);")
        if written_back is not None:
            body.append(f"ctx->r[{ins.rn}] = wb;")
        body.append(f"{dest(ins.rd)} = v;")  # a loaded base wins over the written-back one
    return _scoped(body)


def _block_transfer(ins: Instruction) -> list[str]:
    regs = ins.reglist
    if not regs:
        raise LiftError(f"{ins.addr:#010x}: LDM/STM with an empty register list")
    count = len(regs)
    base = read(ins, ins.rn)
    first = {(False, True): 0, (True, True): 4, (False, False): -4 * count + 4,
             (True, False): -4 * count}[(ins.pre, ins.up)]
    final = f"{base} {'+' if ins.up else '-'} {hexu(4 * count)}"
    restore = ins.user and ins.op is Op.LDM and PC in regs
    user = ins.user and not restore
    body = [f"uint32_t addr = ({base} + {hexu(first)}) & ~3u;", f"uint32_t final = {final};"]
    for i, r in enumerate(regs):
        slot = f"addr + {4 * i}u"
        target = f"*gba_user_reg(ctx, {r})" if user and r != PC else dest(r)
        if ins.op is Op.STM:
            if r == ins.rn and ins.writeback and i > 0:
                value = "final"  # ARMv4: the new base is stored unless it comes first
            elif r == PC:
                value = hexu(pc_value(ins) + 4)
            else:
                value = target
            body.append(f"gba_write32(ctx, {slot}, {value});")
        else:
            body.append(f"{target} = gba_read32(ctx, {slot});")
    if ins.writeback:
        body.append(f"ctx->r[{ins.rn}] = final;")
    else:
        body.append("(void)final;")
    if restore:
        body.append("gba_restore_cpsr(ctx);")
    return _scoped(body)


def _swap(ins: Instruction) -> list[str]:
    load, store = ("gba_read8", "gba_strb") if ins.op is Op.SWPB else ("gba_ldr", "gba_str")
    return _scoped([
        f"uint32_t addr = {read(ins, ins.rn)};",
        f"uint32_t old = {load}(ctx, addr);",
        f"{store}(ctx, addr, {read(ins, ins.rm)});",
        f"ctx->r[{ins.rd}] = old;",
    ])


def _scoped(body: list[str]) -> list[str]:
    return ["{", *("    " + line for line in body), "}"]
```

```python
"""Lift one function of the CFG to a C function.

Every block becomes a label. A branch to a block of the function is a goto;
a branch or fall-through anywhere else leaves the function by returning that
address. (Calls, returns and computed jumps come with the control-flow task.)
"""

from gbaport.analysis.cfg import Function, Program
from gbaport.analysis.discover import Exploration
from gbaport.isa.model import Cond, Instruction, Op
from gbaport.lift.semantics import CONDITIONS, cycles, hexu, lift_effects


def function_name(addr: int, prefix: str = "") -> str:
    return f"{prefix}f_{addr:08x}"


def label(addr: int) -> str:
    return f"L_{addr:08x}"


def lift_function(fn: Function, program: Program, ex: Exploration, prefix: str = "") -> str:
    return _FunctionLifter(fn, program, ex, prefix).lift()


class _FunctionLifter:
    def __init__(self, fn: Function, program: Program, ex: Exploration, prefix: str) -> None:
        self.fn = fn
        self.program = program
        self.ex = ex
        self.prefix = prefix
        self.blocks = set(fn.blocks)
        # The entry block comes first; the rest follow in address order.
        self.order = [fn.entry] + sorted(self.blocks - {fn.entry})

    def lift(self) -> str:
        lines = [f"uint32_t {function_name(self.fn.entry, self.prefix)}(GbaCtx *ctx)", "{"]
        lines += ["    uint32_t t = 0;", "    (void)t;"]
        for i, start in enumerate(self.order):
            following = self.order[i + 1] if i + 1 < len(self.order) else None
            lines += self._block(start, following)
        lines.append("}")
        return "\n".join(lines) + "\n"

    def _block(self, start: int, following: int | None) -> list[str]:
        block = self.program.blocks[start]
        lines = [f"{label(start)}:"]
        lines.append(f"    ctx->cycles += {sum(cycles(ins) for ins in block.instructions)};")
        ended = False
        for ins in block.instructions:
            lines.append(f"    /* {ins.addr:08x} */")
            body, ended = self._instruction(ins)
            if ins.cond is not Cond.AL:
                body = [f"if ({CONDITIONS[ins.cond]}) {{", *("    " + s for s in body), "}"]
                ended = False
            lines += ["    " + s for s in body]
        if not ended:
            last = block.instructions[-1]
            nxt = last.addr + last.size
            if nxt != following:
                lines.append("    " + self._go(nxt))
        return lines

    def _instruction(self, ins: Instruction) -> tuple[list[str], bool]:
        """C for ``ins`` and whether control never falls through to the next instruction."""
        if ins.op is Op.UNDEFINED:
            return [f"gba_undefined(ctx, {hexu(ins.addr)});", f"GBA_EXIT({hexu(ins.addr)});"], True
        if ins.op is Op.B:
            return [self._go(ins.target)], True
        return lift_effects(ins), False

    def _go(self, target: int) -> str:
        if target in self.blocks:
            return f"goto {label(target)};"
        return f"GBA_EXIT({hexu(target)});"
```

```python
"""Lift a whole analysed program: functions, their prototypes and the dispatch table.

The dispatch table maps each recompiled function's address to its C function;
``gba_lookup`` (prefixed in tests, so several programs can share one binary)
finds the function for an address with a binary search and hands anything
else to the runtime's ``gba_missing``.
"""

from dataclasses import dataclass

from gbaport.analysis.cfg import Program
from gbaport.analysis.discover import Exploration
from gbaport.lift.function import function_name, lift_function

HEADER = "gba_cpu.h"
CHUNK = 256  # functions per generated .c file


@dataclass(frozen=True)
class LiftedProgram:
    prefix: str
    prototypes: str  # a declaration for every function
    functions: dict[int, str]  # entry address -> C definition
    dispatch: str  # the sorted table and the lookup function

    @property
    def lookup_name(self) -> str:
        return f"{self.prefix}gba_lookup"


def lift_program(program: Program, ex: Exploration, prefix: str = "") -> LiftedProgram:
    entries = sorted(program.functions)
    prototypes = "".join(f"uint32_t {function_name(a, prefix)}(GbaCtx *ctx);\n" for a in entries)
    prototypes += f"GbaFn {prefix}gba_lookup(GbaCtx *ctx, uint32_t addr);\n"
    functions = {a: lift_function(program.functions[a], program, ex, prefix) for a in entries}
    return LiftedProgram(prefix, prototypes, functions, _dispatch(entries, prefix))


def single_source(lifted: LiftedProgram) -> str:
    """One C file holding the whole program (it includes gba_cpu.h)."""
    parts = [f'#include "{HEADER}"\n', lifted.prototypes, *lifted.functions.values()]
    return "\n".join([*parts, lifted.dispatch])


def program_files(lifted: LiftedProgram, chunk: int = CHUNK) -> dict[str, str]:
    """The generated sources by file name: a header, code files and the dispatch table."""
    files = {"gba_program.h": _program_header(lifted)}
    bodies = list(lifted.functions.values())
    for n, start in enumerate(range(0, len(bodies), chunk)):
        code = '#include "gba_program.h"\n\n' + "\n".join(bodies[start : start + chunk])
        files[f"gba_code_{n:03d}.c"] = code
    files["gba_dispatch.c"] = '#include "gba_program.h"\n\n' + lifted.dispatch
    return files


def _program_header(lifted: LiftedProgram) -> str:
    return (
        "/* Generated by gbaport: declarations of every recompiled function. */\n"
        "#ifndef GBA_PROGRAM_H\n#define GBA_PROGRAM_H\n\n"
        f'#include "{HEADER}"\n\n{lifted.prototypes}\n#endif\n'
    )


def _dispatch(entries: list[int], prefix: str) -> str:
    lines = []
    if entries:
        lines.append(f"static const struct {{ uint32_t addr; GbaFn fn; }} {prefix}table[] = {{")
        lines += [f"    {{0x{a:08x}u, {function_name(a, prefix)}}}," for a in entries]
        lines.append("};")
    lines += [
        "",
        f"GbaFn {prefix}gba_lookup(GbaCtx *ctx, uint32_t addr)",
        "{",
        "    addr &= ~1u;",
    ]
    if entries:
        lines += [
            f"    uint32_t lo = 0, hi = {len(entries)};",
            "    while (lo < hi) {",
            "        uint32_t mid = (lo + hi) / 2;",
            f"        uint32_t found = {prefix}table[mid].addr;",
            "        if (found == addr)",
            f"            return {prefix}table[mid].fn;",
            "        if (found < addr)",
            "            lo = mid + 1;",
            "        else",
            "            hi = mid;",
            "    }",
        ]
    lines += ["    return gba_missing(ctx, addr);", "}"]
    return "\n".join(lines) + "\n"
```

```python
"""Lift one function of the CFG to a C function.

Every block becomes a label. A branch to a block of the function is a goto;
whatever leaves the function (a return, a tail call, a jump through a register)
returns the address to continue at. A call sets LR and runs the callee chain
with ``gba_call`` until it comes back to the return address. Blocks that loops
or switches jump back to check for due events, so long loops still let the
scheduler run.
"""

from gbaport.analysis.cfg import Function, Program
from gbaport.analysis.discover import Exploration
from gbaport.analysis.flow import links_to_next, writes_pc
from gbaport.isa.model import Cond, Instruction, Mode, Op
from gbaport.lift.semantics import CONDITIONS, LiftError, cycles, hexu, lift_effects


def function_name(addr: int, prefix: str = "") -> str:
    return f"{prefix}f_{addr:08x}"


def label(addr: int) -> str:
    return f"L_{addr:08x}"


def lift_function(
    fn: Function,
    program: Program,
    ex: Exploration,
    prefix: str = "",
    problems: list[str] | None = None,
) -> str:
    """C for ``fn``; instructions it cannot express are reported in ``problems``."""
    lifter = _FunctionLifter(fn, program, ex, prefix)
    code = lifter.lift()
    if problems is not None:
        problems += lifter.problems
    return code


class _FunctionLifter:
    def __init__(self, fn: Function, program: Program, ex: Exploration, prefix: str) -> None:
        self.problems: list[str] = []
        self.fn = fn
        self.program = program
        self.ex = ex
        self.prefix = prefix
        self.blocks = set(fn.blocks)
        # The entry block comes first; the rest follow in address order.
        self.order = [fn.entry] + sorted(self.blocks - {fn.entry})

    def lift(self) -> str:
        loop_heads = self._loop_heads()
        lines = [f"uint32_t {function_name(self.fn.entry, self.prefix)}(GbaCtx *ctx)", "{"]
        lines += ["    uint32_t t = 0;", "    (void)t;"]
        for i, start in enumerate(self.order):
            following = self.order[i + 1] if i + 1 < len(self.order) else None
            lines += self._block(start, following, start in loop_heads)
        lines.append("}")
        return "\n".join(lines) + "\n"

    def _loop_heads(self) -> set[int]:
        """Blocks reached by a backward branch, or by a computed jump."""
        heads = set()
        for start in self.blocks:
            block = self.program.blocks[start]
            computed = writes_pc(block.instructions[-1])  # a switch may jump anywhere
            for succ in block.successors:
                if succ in self.blocks and (succ <= start or computed):
                    heads.add(succ)
        return heads

    def _block(self, start: int, following: int | None, loop_head: bool) -> list[str]:
        block = self.program.blocks[start]
        lines = [f"{label(start)}:"]
        lines.append(f"    ctx->cycles += {sum(cycles(ins) for ins in block.instructions)};")
        if loop_head:
            lines.append("    GBA_CHECK_EVENTS();")
        prev = self._predecessor(start, block.mode)
        ended = False
        for ins in block.instructions:
            lines.append(f"    /* {ins.addr:08x} */")
            body, ended = self._instruction(ins, prev)
            if ins.cond is not Cond.AL:
                body = [f"if ({CONDITIONS[ins.cond]}) {{", *("    " + s for s in body), "}"]
                ended = False
            lines += ["    " + s for s in body]
            prev = ins
        if not ended:
            last = block.instructions[-1]
            nxt = last.addr + last.size
            if nxt != following:
                lines.append("    " + self._go(nxt))
        return lines

    def _predecessor(self, start: int, mode: Mode) -> Instruction | None:
        before = self.ex.instructions.get(start - (4 if mode is Mode.ARM else 2))
        if before is not None and self.ex.successors.get(before.addr) == (start,):
            return before
        return None

    def _instruction(self, ins: Instruction, prev: Instruction | None) -> tuple[list[str], bool]:
        """C for ``ins`` and whether control never falls through to the next instruction."""
        op = ins.op
        if op is Op.UNDEFINED:
            return [f"gba_undefined(ctx, {hexu(ins.addr)});", f"GBA_EXIT({hexu(ins.addr)});"], True
        if op is Op.B:
            return [self._go(ins.target)], True
        if op is Op.BL:
            ret = self._return_address(ins)
            callee = self._direct(ins.target)
            return [f"ctx->r[14] = {hexu(ret)};", f"gba_call(ctx, {callee}, {hexu(ret)});"], False
        if op is Op.BL_LO:
            ret = self._return_address(ins)
            return [
                f"t = ctx->r[14] + {hexu(ins.imm)};",
                f"ctx->r[14] = {hexu(ret)};",
                f"gba_call(ctx, t, {hexu(ret)});",
            ], False
        try:
            effects = lift_effects(ins)
        except LiftError as error:  # reported, and handled like an undefined instruction
            self.problems.append(str(error))
            return [f"gba_undefined(ctx, {hexu(ins.addr)});", f"GBA_EXIT({hexu(ins.addr)});"], True
        if not writes_pc(ins):
            return effects, False
        body = effects + self._mask(ins)
        if links_to_next(prev):  # mov lr, pc just before: a call through a register
            return body + ["gba_call(ctx, t, ctx->r[14]);"], False
        return body + self._switch(ins) + ["GBA_EXIT(t);"], True

    def _return_address(self, ins: Instruction) -> int:
        after = ins.addr + ins.size
        return after | 1 if ins.mode is Mode.THUMB else after

    def _direct(self, target: int) -> str:
        """The callee expression for gba_call: a direct C call when it was recompiled."""
        if target in self.program.functions:
            return f"{function_name(target, self.prefix)}(ctx)"
        return hexu(target)

    def _go(self, target: int) -> str:
        if target in self.blocks:
            return f"goto {label(target)};"
        return f"GBA_EXIT({hexu(target)});"

    def _mask(self, ins: Instruction) -> list[str]:
        if ins.op is Op.BX:
            return []  # bit 0 selects the state; the lookup ignores it
        return ["t &= ~3u;" if ins.mode is Mode.ARM else "t &= ~1u;"]

    def _switch(self, ins: Instruction) -> list[str]:
        """Jumps to known cases (jump tables, traced targets) stay inside the function."""
        after = ins.addr + ins.size
        cases = [
            s for s in self.ex.successors.get(ins.addr, ())
            if s in self.blocks and not (s == after and ins.cond is not Cond.AL)
        ]
        if not cases:
            return []
        lines = ["switch (t & ~1u) {"]
        lines += [f"case {hexu(s)}: goto {label(s)};" for s in sorted(set(cases))]
        lines += ["default: break;", "}"]
        return lines
```
